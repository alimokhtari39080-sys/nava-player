# AvaNature / آواطبیعت

A separate offline Android soundscape app is being built on the `avanature` branch.
The project is intentionally isolated from the existing NAVA Player Android module.

- Persian interface and searchable categories.
- Rain varieties, thunder and storm, water, wind, forest, animals, human ambience, relaxation and noise colors.
- One-tap soundscape mixes, simultaneous layers, master volume and sleep timer.
- Background playback notification and offline local audio synthesis.

**Audio disclosure:** version 1 recreates sound effects digitally on the phone. They are not authentic field recordings or real human/animal recordings.

The workflow `.github/workflows/avanature-android.yml` builds a debug APK and publishes it as the GitHub Actions artifact `AvaNature-Android-APK`.
