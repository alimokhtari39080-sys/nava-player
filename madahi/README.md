# نوای هیئت — ماژول اندروید

اپلیکیشن فارسی برای جست‌وجو و مرور مداحی‌ها، با تمرکز ویژه بر حمید علیمی.

## امکانات نسخه ۱.۰

- رابط فارسی راست‌چین و طراحی سازگار با موبایل
- آرشیو اولیه حمید علیمی و پیوند به کانال معرفی‌شده او
- جست‌وجوی عنوان، مداح و مناسبت
- فهرست مداحان پرجست‌وجو و هدایت به جست‌وجوی آثارشان
- علاقه‌مندی‌های محلی روی همان گوشی
- همگام‌سازی فهرست ویدئوهای تازه از RSS یوتیوب هنگام باز کردن برنامه
- حفظ فهرست اولیه برای زمان قطع اینترنت
- ساخت APK آزمایشی از طریق GitHub Actions

## ساخت APK

در مخزن GitHub، به **Actions → Nava Madahi Android APK → آخرین اجرای موفق → Artifacts → Nava-Madahi-Android-debug** بروید و فایل ZIP خروجی را دانلود و استخراج کنید. سپس APK را روی گوشی اندرویدی نصب کنید. برای نصب خارج از Play Store ممکن است لازم باشد اجازه نصب از همان مرورگر یا فایل‌منیجر را بدهید.

## به‌روزرسانی خودکار

فایل `data/sources.json` شناسه کانال‌های یوتیوب را نگه می‌دارد. گردش‌کار `Refresh Madahi catalog` هر ۱۲ ساعت RSS کانال‌های فعال را می‌خواند و اگر ویدئوی تازه‌ای پیدا کند، `src/main/assets/madahi/data/feed.json` را به‌روزرسانی می‌کند. برای اضافه‌کردن مداح جدید، نام، شناسه کانال و نشانی کانال را به `sources.json` اضافه و `enabled` را `true` کنید.

## منابع و حقوق آثار

این برنامه میزبان فایل صوتی نیست و فایل‌های دارای حق نشر را از منابع دیگر کپی نمی‌کند. پیوند هر مداحی کاربر را به صفحه منتشرکننده یا کانال اصلی می‌برد. برای افزودن فایل دانلودی مستقیم، باید اجازه صاحب اثر یا مجوز روشن انتشار وجود داشته باشد.

## وضعیت نسخه

نسخه فعلی یک APK آزمایشی/قابل نصب است و هنوز انتشار در Google Play یا امضای نسخه نهایی انجام نشده است. برای انتشار فروشگاهی، شناسه اپ، سیاست حریم خصوصی، کلید امضای اختصاصی و بررسی نهایی لازم است.
