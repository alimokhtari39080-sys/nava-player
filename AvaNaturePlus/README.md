# AvaNature Plus — آواطبیعت پلاس

Independent second installation of AvaNature. It uses a different Android application ID so version 1 and Plus can coexist.

## Features
- Dynamic visual themes: Rain, Forest, Thunderstorm, Animals, Ocean, Deep Bass, Human & City, Calm & Sleep, Fire & Camp, Space.
- Theme-specific cards, colors, backgrounds and sound libraries.
- Layered mix presets, individual sound toggles and master volume.
- Favorites, sound search, sleep timer and foreground background playback.
- New mountain-waterfall-headphones launcher icon.
- Offline synthesized audio textures; animal and nature sounds are explicitly disclosed as synthetic rather than field recordings.

Build: GitHub Actions workflow `.github/workflows/avanature-plus-android.yml` publishes `AvaNature-Plus-Android-APK`.
