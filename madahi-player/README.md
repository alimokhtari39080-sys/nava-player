# نوای هیئت پلاس — پخش‌کننده فقط صوت

این ماژول، نسخه دوم مستقل از اپ اصلی «نوای هیئت» است. نسخه اول در مسیر `madahi/` بدون تغییر باقی می‌ماند.

## تجربه پخش
- لمس هر مدخل، صدای MP3 را مستقیماً در پخش‌کننده صوتی داخل برنامه پخش می‌کند.
- هیچ ویدئو یا پخش‌کننده YouTube در نسخه صوتی وجود ندارد.
- کنترل پخش/توقف، جلو و عقب، نوار زمان و علاقه‌مندی‌ها در برنامه وجود دارد.
- فهرست اولیه شامل ۹ ترک صوتی حمید علیمی است که صفحه هنرمند و صفحات ترک آن‌ها در Sonalos در دسترس‌اند.
- برنامه فایل صوتی را در GitHub کپی یا میزبانی نمی‌کند؛ درخواست پخش به نشانی MP3 منتشرشده توسط منبع هدایت می‌شود.
- تب‌های همه، تازه‌های فهرست، آرشیو قدیمی و نشان‌شده‌ها.
- بررسی فهرست صوتی هر حدود ۱۲ ساعت با اتصال اینترنت و اعلان در صورت اضافه‌شدن شناسه‌های جدید؛ زمان دقیق بهینه‌سازی با اندروید است.

## منبع صوت
پیوندهای صوتی در `src/main/assets/player/data/catalog.json` ثبت شده‌اند. در این نسخه، پخش بر اساس لینک‌های MP3 که در صفحه‌های ترک Sonalos ارائه شده‌اند انجام می‌شود. در دسترس بودن این دامنه/CDN از داخل ایران به وضعیت شبکه و محدودیت‌های همان سرویس بستگی دارد؛ برنامه وابستگی به YouTube ندارد، اما نمی‌توان دسترسی شبکه به هر سرویس ثالث را تضمین کرد.

## اضافه‌کردن مداحی جدید
برای هر ترک، فقط پس از اطمینان از مجاز بودن پخش در اپ، رکوردی با فیلدهای `id`, `title`, `maddah`, `audioUrl`, `sourcePage`, `source`, `quality`, `group`, `order` و `type: "audio"` به فایل JSON اضافه کن. `audioUrl` باید HTTPS و متعلق به منبع صوتی مجاز باشد. فایل‌های دارای حق نشر را در مخزن GitHub قرار نده.

## ساخت APK
GitHub Actions → Nava Madahi Plus Android APK → آخرین اجرای موفق → Artifacts → Nava-Madahi-Plus-Android-debug

ساخت محلی:
`gradle --no-daemon :madahi-player:assembleDebug`

ماژول اول `madahi/` حفظ شده و شناسه نصب این نسخه جداگانه باقی می‌ماند.
